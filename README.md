# Dual-AAV Bioprocessing Digital Twin

**Integrated repository containing the user-uploaded manuscript, computational source repository, figure/publication archives, and extracted manuscript tables.**

## Manuscript included
The exact uploaded manuscript is preserved as:
- `manuscript/AAV_Manuscript_FINAL_DRAFT_UPLOADED.docx`
- `manuscript/AAV_Manuscript_FINAL_DRAFT_preview_UPLOADED.pdf`

A separate conservative editorial-repair manuscript is retained as a reference only:
- `manuscript/AAV_Modular_Dual_AAV_Manuscript_EDITORIAL_REPAIR_v2_REFERENCE.docx`

The uploaded manuscript is preserved as supplied; its numerical claims have not been silently edited or certified. Read `MANUSCRIPT_RELEASE_STATUS.md` before using it.

## Tables
`manuscript/tables/AAV_ALL_TABLES_FROM_UPLOADED_MANUSCRIPT_AND_SUPPLEMENT_DRAFT.xlsx` contains extracted tables from the uploaded manuscript and the available supplementary repair draft. Supplementary tables remain draft status.

## Source archives
`source_archives/` contains the uploaded publication package, figure archive, and original public repository snapshot for traceability. The private bundle containing the adapted upstream Python port is deliberately excluded.

## Tests
Run `python run_all.py` to execute the public repository's regression tests. Passing tests demonstrate only the tested software paths, not biological validation or proof of every manuscript claim.

## Release status
This repository is an integrated **private review candidate**, not cleared for public GitHub release or journal submission. See `MANUSCRIPT_RELEASE_STATUS.md` and `docs/PERMISSION_STATUS.md`.
